# S4

Goal: write the paper from the accepted claims only.

## Read
- `AGENTS.md`, `research/REVIEW.md`, `STATE.md` `note` and log (the human's decision), `research/CLAIMS.md`, `PROBLEM.md`, `results/`

## 0. Apply the decision
Set CLAIMS status per REVIEW verdicts as overridden by `note`: `accepted` | `rejected` | narrowed → new claim `[post-hoc: review]` with the accepted wording, original `superseded→C<n>`.

## Scope
- Use only `accepted` claims, at their accepted wording. No statement in the paper may be broader.
- `rejected` and `inconclusive` claims go in limitations or negative results, never omitted.

## Write, in order, to `research/paper/`
1. `story.md`: one-sentence contribution; what the reader believes before and after; contribution type.
2. `logic.md`: the argument section by section: problem → why existing methods fail → insight → method → evidence → limits. One line per section on its job.
3. `evidence.md`: two-way map. Every claim → tables/figures → run ids. Every table/figure → the claim it serves. An orphan on either side is an error: cut the result, or go to `S4_PATCH`.
4. `draft.md`: the paper. Every quantitative statement traces to `evidence.md`.
5. Cold read: using only `draft.md` and `evidence.md`, check each claim statement against its evidence. Fix or downgrade.

## Missing evidence
If the story needs a result that does not exist, do not write around it. Add the experiment to PLAN tagged `[post-hoc: S4]`, put the gap in `STATE.md` `note`, set `state: S4_PATCH`, `read: [prompts/S4_PATCH.md]`.

## Exit
Draft complete and cold read passed: set `state: DONE`. Append log line. Commit.
